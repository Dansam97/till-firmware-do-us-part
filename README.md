A one-line robot wedding vow, written by a small Python program. The program writes a single sentence — a robot promising at its own wedding to never reboot mid-argument and to spend its battery's final percent on its partner — to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
